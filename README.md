# NTAA - Not That App Again

1. Put both EXE files in the folder with your `card_data_*` and/or `en_*` bundles.
2. Run `NTAA-Extract.exe` to get `Cards.json` and `English.csv`.
3. Edit the files.
4. Run `NTAA-Import.exe` to replace the bundles with your edits.

Keep only one matching bundle of each kind, one JSON file, and one CSV file in the folder.

Move existing JSON/CSV exports out of the folder before extracting again.
You do not need to extract every time. Just make your edits and import.

Press Enter to close the window. Add `--no-pause` when running from a script.
